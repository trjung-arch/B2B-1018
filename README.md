# 메디린 B2B UI

제공된 B2B-1018-main의 HTML과 빌드된 JavaScript/CSS를 사용해 기존 UI를 재현합니다.

## 실행

프로젝트 폴더에서 `npm run dev`를 실행하고 http://127.0.0.1:3000 에 접속합니다. Python 3가 필요하며 npm 패키지 설치는 필요하지 않습니다.

## 파일

- `index.html`: 진입 페이지
- `assets/`: 제공된 React 앱의 빌드 결과

원본에는 React/TypeScript 편집용 소스가 포함되어 있지 않습니다. 현재 UI는 제공된 빌드 결과를 그대로 실행합니다. 웹폰트 및 앱에서 참조하는 외부 리소스는 인터넷 연결이 필요할 수 있습니다.
